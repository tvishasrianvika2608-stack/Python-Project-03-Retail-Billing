# Project 3: Retail Billing with Multiple Discount Rules

## Problem Description
This project generates a retail bill by processing multiple products, their quantities, category-specific taxes, and discount rules. It calculates the subtotal, total tax, discount amount, and final payable amount while applying a maximum discount limit.

## Programming Language
Python

## Concepts Used
- Variables and data types
- Lists and tuples
- For loops
- Conditional statements (if, elif, else)
- Arithmetic operators
- User input and output

## Files Included
- `Question_03_Retail_Billing.py` – Python source code
- `Screenshots/` – Code and output screenshots

## How to Run
1. Download the Python file.
2. Open it using Python or VS Code.
3. Run the program.
4. Enter the details of three products.
5. View the generated retail invoice.

## Conclusion
The program calculates product amounts, applies category-specific taxes and discount rules, and generates an itemized retail invoice with the final payable amount.
